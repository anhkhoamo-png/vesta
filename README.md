# VESTA — GitHub Showcase

A static, GitHub Pages-ready showcase for VESTA. It presents five outfit styles inside a smart-mirror interface. Clicking a style changes the person shown in the mirror.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder, keeping the `assets` folder next to `index.html`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will provide the public site URL.

No Node.js, database, API key, or backend is required.

## Important asset note

The five local JPGs are cropped from the VESTA concept artwork. They are included so the site works immediately. For the strongest final presentation, replace them with five professionally generated/photographed full-body images using the same model, camera angle, background, crop, and pose.
